# Arduino Uno · потенціометр керує серво

Крутіть ручку потенціометра: C++ задає серво кут від 0° до 180°.

Потенціометр: leg1 → GND, leg2 → 5V, wiper → A0. Серво: gnd → GND, vcc → 5V, pulse → D9. Рухайте повзунок у «Контакти» або тягніть по колу ручку на полотні; стрілки клавіатури теж працюють.

Відкрийте circuit.wire.json у WireDroid, натисніть «Код» для редагування sketches/uno.cpp і «Запустити» для цифрової GPIO-візуалізації.

Розміри деталей змінюються окремо в інспекторі (25–200%). Приклад можна змінювати й експортувати як звичайний проєкт.

Це цифрова GPIO-модель. Приклад не містить SDK виробника або прошивання фізичної плати.
