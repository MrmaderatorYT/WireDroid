Розрахунок електроніки
Напруга, струм, RC/RL, діоди, транзистори та двигуни. Параметри моделей змінюються в інспекторі. Окремі режими: C/C++ GPIO, AVR MCU та фізична плата через USB. Перегляньте можливості у «Проєкт».
Готово
Немає сигналу
Канали, тригер та декодування
Для I²C/SPI оберіть канали у вказаному порядку. Декодування використовує записані або позначені відновлені фронти.
Час фронтів C++ — у мікросекундах; несуча PWM розраховується з частоти та заповнення. Це не тактова емуляція мікроконтролера.
Запустіть AVR MCU
Адреси PC — байтові. Фронти AVR мають часові мітки тактів. Обмін між MCU та розрахунок схеми виконуються квантами 1 ms.

Налаштування та підтримка
Ваша схема, ваш код
Додайте деталі з бібліотеки. Рухайте їх пальцем або мишею. Вибрану деталь можна зменшити або збільшити кнопками −▣ / +▣ чи повзунком «Розмір деталі» у вкладці «Контакти» (25–200%). Розмір зберігається разом зі схемою. Кнопка «Приклади» створює окремий проєкт із готовою платою, дротами та C++ програмою. У режимі «З’єднати» торкніться двох контактів. Торкніться дроту, щоб змінити колір, маршрут або видалити. У вкладці «Контакти» додайте точки перегину та рухайте їх на полотні. Кнопка ┐ прокладає нові проводи під прямим кутом. Вибраний дріт підсвічує свій електричний ланцюг. «Перевірити» показує помилки та попередження; натискання переводить до деталі.
Виберіть плату й натисніть «Код». Програми зберігаються у sketches/<ID плати>.cpp. Arduino-скетчі .ino також підтримуються. Код відкриється у вкладці IDE. Натисніть «Запустити» у правій панелі: зміни коду збережуться перед компіляцією.
#include <Arduino.h>

void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}
Доступні стандартні типи C++17, Arduino String/Print/Stream, бібліотеки з папки libraries/, Wire, SPI, EEPROM, LiquidCrystal, Stepper, Servo. Файли src/ та include/ входять до проєкту. Доступні: pinMode, digitalWrite, digitalRead, analogWrite, analogRead (розрядність у профілі плати), delay, millis, Serial.print / println / write / available / read / peek. Вкладка Serial дозволяє надсилати дані програмі. Вкладка «Сигнали» показує HIGH/LOW, PWM/ADC і графік останніх 10 секунд. Кожна плата виконує власну C++17 програму GPIO в окремому процесі. Контакт можна вказати числом, назвою або рядком «connectorID» з інспектора. Запуск потребує ARM64 Android. GPIO — параметрична симуляція на Android. Для Uno/Nano доступний імпорт HEX, виконання AVR та протокол STK500v1 через USB. Точна підтримка наведена у «Проєкт → Плати». Кнопку можна натискати на полотні під час запуску або через інспектор. У потенціометра змінюйте положення повзунком; у підтриманого аналогового входу — значення ADC. Для інших датчиків можна обрати контакт ручного сигналу, без моделювання протоколу датчика.
Колесо / два пальці — масштаб; порожнє полотно — панорама. Ctrl+S — зберегти, Ctrl+Z — скасувати, Delete — видалити. Живлення та GND з’єднані одночасно: симуляція зупиниться з повідомленням.
