# ESP32 QT Py · миготіння LED

Модуль ESP32, вихід A0, резистор і LED.

A0 (connector17) → 220 Ω → LED → GND (connector41). Контакт вибрано за ID з каталогу. Приклад демонструє загальну GPIO-модель модуля, а не ESP-IDF чи емуляцію CPU ESP32.

Відкрийте circuit.wire.json у WireDroid, натисніть «Код» для редагування sketches/esp32.cpp і «Запустити» для цифрової GPIO-візуалізації.

Розміри деталей змінюються окремо в інспекторі (25–200%). Приклад можна змінювати й експортувати як звичайний проєкт.

Це цифрова GPIO-модель. Приклад не містить SDK виробника або прошивання фізичної плати.
