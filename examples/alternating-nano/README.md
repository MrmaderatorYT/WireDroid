# Arduino Nano · два LED

Червоний і зелений LED по черзі на D2 та D3.

D2 керує червоним LED, D3 — зеленим. Кожен LED має власний резистор 220 Ω та з’єднання катода з GND.

Відкрийте circuit.wire.json у WireDroid, натисніть «Код» для редагування sketches/nano.cpp і «Запустити» для цифрової GPIO-візуалізації.

Розміри деталей змінюються окремо в інспекторі (25–200%). Приклад можна змінювати й експортувати як звичайний проєкт.

Це цифрова GPIO-модель. Приклад не містить SDK виробника або прошивання фізичної плати.
