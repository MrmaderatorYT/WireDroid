# Готові приклади WireDroid

- **Arduino Uno · миготіння LED** — `blink-uno/`: Uno + резистор + LED; увімкнення та вимкнення кожні 500 мс.
- **Arduino Uno · кнопка та LED** — `button-uno/`: Кнопка на D2 з INPUT_PULLUP керує LED на D13.
- **Arduino Uno · світлофор** — `traffic-uno/`: Три LED на D8, D9 і D10 з окремими резисторами.
- **Arduino Nano · два LED** — `alternating-nano/`: Червоний і зелений LED по черзі на D2 та D3.
- **ESP32 QT Py · миготіння LED** — `blink-esp32/`: Модуль ESP32, вихід A0, резистор і LED.
- **Arduino Uno · рух сервопривода** — `servo-sweep/`: Серво плавно повертається між 0° та 180°.
- **Arduino Uno · потенціометр керує серво** — `servo-pot/`: Крутіть ручку потенціометра: C++ задає серво кут від 0° до 180°.

У застосунку: «Приклади схем» на початковому екрані або «Приклади» у конструкторі. Кожне відкриття створює окремий редагований проєкт.
